# 📸 Instagram Clone

A responsive and interactive Instagram UI clone built using **HTML**, **Tailwind CSS**, and **Vanilla JavaScript**. Features include stories, posts, suggestions, and like interactions—just like the original Instagram experience.

---

## 🔥 Features

- 📷 **Stories UI** with scroll and touch support
- 🖼️ **Post feed** with user avatars, captions, and like/comment/bookmark actions
- 💬 **Suggestions** section showing related users to follow
- ❤️ **Like animations** and toggling (filled/empty heart)
- 🎯 **Fully responsive** layout and design
- 📱 **Touch gesture** support for mobile users (swipe to reveal more stories)
- 🖱️ **Smooth scroll and drag interaction** for desktop story navigation
